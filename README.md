# Sam's Sipariş Otomasyonu

Mobil öncelikli masa ve sipariş takip MVP'si. 7 masa, gerçek Sam's menüsü, açık hesap saklama, nakit/kart kapanış, gün sonu özeti ve PWA desteği içerir.

## Sürüm

v0.12: Sipariş otomasyonunun kullanıcı/PIN sistemi öncesindeki kararlı sürümü.

## Geliştirme ortamı

Bu dal (`develop`) test ve yeni özellikler içindir. Canlı üretim dalı `main` korunur. Değişiklikler test edilmeden `main` dalına aktarılmamalıdır.

## Test yayını

`develop` dalı sadece test sürümlerini yayınlamak için kullanılır. Bu değişiklik ilk test deployment'ını tetiklemek içindir.
